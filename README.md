## ✨ 这是什么？

一个 **Chrome 浏览器扩展**，安装后会在你浏览 B站 时，自动在每个视频封面上叠加可爱的 **BanG Dream! 角色贴纸**。

简单来说就是：**打开B站首页 → 每个视频封面角落都冒出一个邦多利角色 → 你的B站变成了邦多利世界**。

> "这不是 bug，这是 feature —— 每个视频都值得被一位邦多利女孩守护。"

## 🚀 核心功能

- **随机混合模式** — 从所有乐队的贴纸池中随机抽取，每次刷新都是惊喜
- **指定乐队模式** — 只显示你最喜欢的那个乐队的角色
- **角色筛选** — 可以精确到具体角色（比如只看灯灯或只看索世）
- **出现概率控制** — 0%~100% 自由调节，想密集就密集，想稀疏就稀疏
- **大小缩放** — 贴纸尺寸 50%~150% 可调
- **确定性哈希** — 同一个视频永远显示同一个贴纸（不会每次刷新都变）
- **智能定位** — 自动识别 B站视频卡片结构，贴纸精准落在封面角落

## 📦 安装方法

### 方式一：开发者模式加载（推荐）

1. 克隆或下载本项目到本地
2. 打开 Chrome，访问 `chrome://extensions/`
3. 开启右上角 **「开发者模式」**
4. 点击 **「加载已解压的扩展程序」**
5. 选择项目根目录
6. 完成！点击扩展图标即可开关

### 方式二：打包安装

```bash
# 在项目根目录执行
# Chrome 扩展菜单 → 打包扩展程序 → 选择本目录 → 生成 .crx 文件
```

## ⚙️ 使用说明

### 快速开关

点击浏览器工具栏中的 **扩展图标**，弹出面板中一键开启/关闭：

```
[★ 邦多利贴纸 ★]
┌─────────────────────┐
│   🎸 当前已开启      │  ← 点击切换
│       点击关闭       │
│                     │
│  🎵 随机混合（全部乐队）│
│                     │
│     [ 更多设置 → ]    │
└─────────────────────┘
```

### 详细设置

点击「更多设置」进入设置页，你可以：

1. **选择显示模式**：随机混合 or 指定乐队
2. **挑选乐队和角色**：9 支乐队 + 各乐队成员多选
3. **调出现概率**：滑块控制 0% ~ 100%
4. **改贴纸大小**：滑块控制 50% ~ 150%

## 🔧 技术亮点

| 特性 | 说明 |
|------|------|
| **Manifest V3** | 采用最新的 Chrome 扩展规范 |
| **FNV-1a 哈希** | 确保同一视频始终映射到相同贴纸，不会闪烁跳变 |
| **MutationObserver** | 实时监听 B站 SPA 动态加载的内容 |
| **智能 DOM 遍历** | 自动爬升 DOM 树找到最佳定位容器，适配 B站复杂的卡片嵌套结构 |
| **并发探测回退** | 无文件清单时自动探测可用图片资源 |
| **双通道设置同步** | `storage.onChanged` + 焦点轮询双重保障，设置变更立即生效 |
| **玻璃态 UI** | 弹窗采用「梦幻偶像演唱会门票」风格，设置页采用「偶像收藏专辑」风格 |

## 🎮 彩蛋 & 细节

- 贴纸有 **4 个预设位置**（四角），由哈希决定落在哪个角落
- 每张贴纸还有 **72% ~ 108% 的随机尺寸变化**，看起来更自然
- 贴纸自带 **投影效果** (`drop-shadow`)，增加立体感
- 鼠标悬停视频卡片时贴纸会 **自动隐藏**，不遮挡预览图
- 弹窗按钮有 **涟漪动画** 点击反馈
- 设置页滑块有 **渐变色填充** 轨道
