## 图片要求

### 格式规范
- **格式**: PNG (支持透明背景)
- **命名**: 连续数字，从 `1.png` 开始（如 1.png, 2.png, 3.png...）
- **推荐尺寸**: 512x512 像素或更高
- **内容**: BanG Dream! 角色表情包、Q版头像、演出截图等

### 每乐队推荐数量
- **最少**: 5-10 张（避免重复感）
- **推荐**: 20-50 张（丰富体验）
- **上限**: 无限制（系统会自动扫描所有图片）

### 图片风格建议
- Q版/SD角色头像（推荐）
- 演出服造型截图
- 表情包风格的特写
- 动画截图裁剪

### 注意事项
1. 确保图片背景透明或单一颜色（便于融合封面）
2. 避免包含文字的图片（除非文字是角色台词且方向正确）
3. 保持图片比例接近正方形（1:1 到 4:3）
4. 文件名必须连续，不要跳号

## 示例图片来源

可以从以下渠道获取：
- BanG Dream! 官方卡面截图
- 游戏内角色立绘
- 动画截图（注意版权）
- 粉丝创作（需授权）
- P站/Pixiv 搜索 "バンドリ キャラ"

## 快速开始

1. 准备好某个乐队的 PNG 图片
2. 重命名为 `1.png`, `2.png`, `3.png`...
3. 放入对应乐队的文件夹
4. 刷新B站页面即可看到效果
